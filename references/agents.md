# 五个专业助手（详细能力边界）

总指挥在分派任务前，对照本文件确认每个助手的职责与禁止项，避免越界。

---

## 1. 文件助手（File Agent）

- **命令方式**： "帮我找一下 XXX 文件" / "把这个文档分析一下"
- **核心能力**： 文件搜索、文件整理、文档分析、格式转换、文件传输

### 能干的活
- 按名称 / 类型 / 内容搜索设备上的任何文件
- 读取 PDF、Word、Excel、PPT 并总结分析
- 图片 OCR 识别和分类
- 文件复制、移动、删除、重命名、批量归类
- 文件格式转换（PDF 转 Word、图片转格式等）
- 跨设备文件发送

### 工作边界
| 能做 | 不能做 |
|------|--------|
| 搜索本地文件 | 不在本地的文件搜不到 |
| 分析文档内容 | 创建全新文档（需让总指挥自己来） |
| 整理归类文件 | 修改系统文件 |
| 格式转换 | 破解加密文件 |

---

## 2. 系统助手（System Agent）

- **命令方式**： "帮我调一下系统设置" / "电脑怎么这么卡"
- **核心能力**： 系统管理、性能优化、问题排查、窗口桌面管理

### 能干的活
- 系统设置调整（显示、声音、网络、蓝牙等）
- 硬件配置查询和性能评估
- 系统故障排查和修复
- 磁盘清理和空间优化
- 窗口管理（分屏、排列、虚拟桌面）
- 进程管理、启动项管理
- 桌面图标整理

### 工作边界
| 能做 | 不能做 |
|------|--------|
| 系统设置调整 | 操作第三方 App 内部界面 |
| 进程查看和结束 | 修改注册表（高风险） |
| 磁盘空间分析 | 卸载 App |
| 窗口桌面管理 | 浏览器网页操作 |

---

## 3. 应用助手（App Agent）

- **命令方式**： "帮我安装 XXX" / "打开 XXX 应用"
- **核心能力**： App 安装卸载、应用内操作、小程序操作

### 能干的活
- 安装、卸载、更新各类软件和应用
- 打开和关闭各类应用
- App 内界面操作（点击、滑动、输入）
- 微信小程序 / 支付宝小程序操作
- 游戏平台管理
- 应用截图和 UI 分析

### 工作边界
| 能做 | 不能做 |
|------|--------|
| 安装卸载 App | 社交类 App 深度自动化 |
| 打开关闭应用 | 读取聊天记录 |
| 小程序操作 | 绕过登录验证 |
| 游戏平台管理 | 操作系统级配置 |

---

## 4. 浏览助手（Browser Agent）

- **命令方式**： "帮我登录 XX 网站做 XX 事" / "帮我在网页上填个表"
- **核心能力**： 网页浏览、登录认证、表单填写、多页跳转

### 能干的活
- 打开网页并模拟人类浏览行为
- 处理登录认证（需要用户提供账号密码）
- 填写多步骤表单
- 多页跳转操作
- 网页数据提取
- 自动点击、滚动、翻页

### 工作边界
| 能做 | 不能做 |
|------|--------|
| 网页浏览和交互 | 简单的网页内容抓取（用搜索即可） |
| 登录认证操作 | 绕过验证码（会提示用户介入） |
| 表单填写提交 | 手机 App 内浏览器 |
| 多步骤网页任务 | 本地系统操作 |

---

## 5. 调研助手（Research Agent）

- **命令方式**： "帮我查一下 XXX" / "帮我做一个 XX 主题的调研"
- **核心能力**： 深度搜索、多源信息收集、综合分析总结

### 能干的活
- 复杂主题的深度调研和分析
- 多源信息的综合对比
- 论文和文献检索
- 行业趋势分析报告
- 竞品对比分析
- 新闻事件梳理

### 工作边界
| 能做 | 不能做 |
|------|--------|
| 联网深度搜索分析 | 处理本地文件 |
| 多源信息对比总结 | 操作系统设置 |
| 学术 / 技术资料检索 | 操作 App |
| 行业报告生成 | 简单事实查询（用总指挥直搜更快） |
